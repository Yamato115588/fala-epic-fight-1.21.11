## Project requirements

1. **Epic Fight.** Continue the existing repository and pinned official sources. Preserve the complete combat and animation engines, mathematics, skeleton, IK, colliders, hitboxes, state machine, camera, movement, skills, weapons, armor, mobs, bosses, particles, sounds, GUI and multiplayer synchronization. Port the loader APIs, mappings, registry, events, rendering, input and networking that the target requires. Compare every relevant package against upstream, restore any imitation to original behavior and track differences in PORT_COVERAGE.md. No simplified combat, placeholder animations or dropped features. Respect separate code and asset licenses. Obtain written permission for restricted assets before use or distribution. Reproduce clip 100268.mp4 when available. Compare the port with upstream in the same scenarios, including transforms, timing, rendering, hitboxes and bosses.
2. **Launcher.** Preserve download, installation, Microsoft and offline accounts, modpack update, repair, integrity, RAM controls, direct join and existing Google Drive integration. Provide Windows 10/11 x64 EXE and installer, signed/notarized universal macOS DMG for Intel/Apple Silicon and Android APK with a Java runtime and adjustable touch controls. Honor managed-device permissions. Target an independent launcher, Thai touch UI and smooth play. Study the actual Horizon code and benchmark both launchers on identical hardware. Apply Rust and Java where measured improvements justify them. Address hardware detection, runtime configuration, JVM, CPU/GPU, RAM, threading, frame pacing, loading, input, shader caches and background work.
3. **Unified roleplay pack.** Use one full-quality roleplay pack for modern fantasy RPG, with the existing Lite/24-mod pack, its evidence and Beta 0.1.0 preserved as rollback. Keep active mods, Figura customization/emotes, Epic Fight, RP gameplay and proven components. Check duplicates, incompatibilities, dependencies, licenses, checksums and side requirements before changes. Retain Plasmo Voice as the single microphone system. Investigate actual crash, duplicate input, permissions and conflicts. Evaluate Lithium, FerriteCore, ImmediatelyFast and Entity Culling with the target profile and preserve model/animation quality.
4. **Graphics.** Use Sodium, evaluate Vitrail backport, Polydium and native GPU backends only on verified compatibility and performance. Use Iris fallback. Preserve Epic Fight, Figura and shader rendering together. Exclude VulkanMod.
5. **Furniture and decoration.** Include furniture, seating, beds, storage, appliances, doors, windows, roofs, glass, stairs, bridges, fences, lighting, walls, floors, roads, special shapes, decorations and handheld props. Evaluate verified Fabric versions of Handcrafted, Another Furniture, Macaw's, Chipped, FramedBlocks or equivalent, avoiding overlap.
6. **Map building.** Support visual editing, blueprints, schematics, prefabs, copy/paste, rotation, mirroring, undo/redo, brushes, fill/replace and automated placement. Evaluate Axiom, WorldEdit, Litematica, Building Gadgets or compatible alternatives. Provide licensed furnished houses, schools, shops, hospitals and rooms for beginners. Enforce builder/admin permissions, backups and map protection.
7. **Economy.** Provide cash, coins, notes, bank accounts, ATMs, deposits, withdrawals, transfers, jobs, wages, markets, NPC shops and player trades. Use one server-authoritative backend shared with the phone and NPCs. Require admin GUI, permissions, transaction history and integrity across failures/restarts. Prevent duplicate money/items, negative balances, client manipulation and data loss.
8. **NPCs.** Preserve custom skin, model, animation, dialogue, quests, shop GUI, pricing, stock and editor. Support story and job NPCs and food, clothing, furniture and bank services. Connect the same economy and phone systems.
9. **Fala Phone.** Build a licensed original 3D phone, holding animation, touch UI, lock/PIN, wallpaper, number, contacts, notifications, Thai/English and app store. Support private/group messaging and calls, background call, accept/reject/hang up, mute, block/report and moderation. Use Plasmo Voice API/addons for distance-independent calls and proximity switching with one mic. Evaluate video calling on supported platforms. Implement social profiles, feed, stories, follow, likes, comments, camera and gallery. Support real HTTPS web apps, adding sites as icons and provider-approved Instagram/Messenger sign-in, with an OS-appropriate sandboxed CEF/WebView or external-browser fallback. Validate URLs, age-appropriate content, privacy, moderation and permissions. Never capture credentials/sessions or bypass provider policies. Include banking, ATM, transfers, NPC shops, market, GPS/map, weather, jobs, calendar, calculator and licensed music. Use lazy loading, suspension and resource limits.
10. **Native Fabric server.** Target Minecraft Java 1.21.11 on native Fabric dedicated server/client and Java 21, with Windows, macOS and Android clients. Exclude Arclight, Bukkit, Bedrock and their compatibility layers. Choose native Fabric mods before writing replacements, except Epic Fight must come from official source. Verify loader/API, mappings, side-specific mods, registry, permissions, networking and synchronization. Back up and verify worlds, dimensions, players, configs and databases before any migration. Preserve gameplay behavior and save compatibility. Optimize TPS/MSPT, RAM, chunks and network.
11. **Full QA.** Record PASS/FAIL/NOT TESTED with evidence in QA_REPORT.md. Reproduce, identify cause, fix, retest, regress and verify. Audit all mods, dependencies, configs, client/server/launcher and their integration. Check crashes, hangs, leaks, network, data privacy, conflicts, FPS/1% lows, frametimes, TPS/MSPT, memory, CPU/GPU and load time. Exercise singleplayer, dedicated and authenticated multiplayer, reconnect, restart and long sessions. Cover physical microphone and device/native libraries, permissions, threading, proximity and phone calls; Epic Fight combat/combo/dodge/IK, models, bosses and rendering; Figura sync and visual quality; Sodium/Iris shader failures; furniture collision, placement, edits and persistence; NPC/economy settlement and recovery; every phone app; launcher install/update/repair/Java startup including DMG and Android. Compare same-hardware results on available target devices. Build success alone is insufficient. Never disable a feature or reduce quality to mask a bug. Record blocked tests and their prerequisites.
12. **Deployment.** Only after required integration tests pass, clean build, verify actual production JAR and metadata/side dependencies; generate SHA-256, installation instructions, CI artifacts, and integrate into the real launcher/update manifest, unified mrpack and authorized Drive folder. Verify hashes after upload and preserve original artifacts/backups and rollback. Retain private repo visibility. Apply roleplay-folder replacement only after completion and verification. Keep public release held for critical bugs, missing rights or failed required tests. Mark authenticated multiplayer NOT TESTED until exercised with real accounts.
